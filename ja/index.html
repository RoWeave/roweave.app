ダウンロード

Excelを列ごとに分割。 レポートを1つに結合。

RoWeaveは、表の行を支店・部署・担当者ごとの別ファイルに振り分けます。見出し、列幅、数値の書式は元の表のままです。逆に、フォルダー内のレポートを1つの表にまとめることもできます。

毎月この作業を 手作業でしているなら

フィルター、コピー、新しいファイル、貼り付け、列幅の調整。これを部署の数だけ繰り返していませんか。あるいは、作った人にしかわからないマクロに頼っていませんか。

  • 経理・財務

    部門ごとにレポートを配布

    全社のレポート1つ → 部門ごとのファイル。見出しも数値の表示形式もそのままです。

  • 人事

    管理職に自部署の社員分だけを渡す

    社員名簿 → 部署ごとのファイル。ファイルごとに別のパスワードを設定でき、パスワードはRoWeaveが別の一覧に保存します。

  • 物流・倉庫

    倉庫ごとのレポートを1つの表に

    各拠点からの30ファイル → 1つの表。各行に元のファイル名を付けることもできます。

  • 営業管理

    予実表を営業担当者ごとに配布

    CRMから出力したデータ（「地域」と「担当者」の列）→ 地域ごとのフォルダー。その中に担当者ごとのファイルを作成します。

  • 会計システム・銀行

    先頭のゼロを消さずにCSVを開く

    CSV → XLSX。商品コード、取引先コード、口座番号が出力時のまま残ります。

  • 学校・大学

    名簿をクラス・グループごとに分ける

    全体の名簿 → グループごとのファイル。あとで先生方のファイルを1つのブックにまとめ直すこともできます。

詳しく見る

商品コードや取引先コードの先頭のゼロが消えず、長い番号が「1.2E+15」に変わることもありません。文字コードは自動で判別します（UTF-8、UTF-16、Shift_JIS、中国語のGBK/GB18030、韓国語のCP949、欧州言語向けのWindows-1252・Windows-1250、トルコ語のWindows-1254、ベトナム語のWindows-1258、キリル文字のWindows-1251・KOI8-R）。判別に自信がないときは、プレビューを表示して確認します。大きなデータも少しずつ読み込み、800万セルまで対応します。

使い方

  1. 1

    ファイルをドロップ

    ブック1つでも、複数のファイルでも、フォルダーごとでもかまいません。XLSX、XLSM、XLS、XLSB、CSV、TSV、TXTに対応しています。

  2. 2

    結果を事前に確認

    シートと列を選びます。作成されるファイルの一覧が表示され、引き継がれない要素があれば警告が出ます。

  3. 3

    結果を保存

    新しいファイルは指定したフォルダーに保存されます。元のファイルは変更されず、過去の処理は「履歴」に残ります。

これまでのやり方

  • 手作業

    フィルター → コピー → 新しいファイル → 貼り付け → 書式の修正。これを40回。1つ間違えれば、関係のない人にデータが届いてしまいます。

  • VBAマクロ

    作った人がいるうちは動きます。Macでは動かないことが多く、マクロ付きのファイルを禁止している会社も少なくありません。

  • オンラインツール

    給与や顧客のデータを、他社のサーバーにアップロードする必要があります。

  • RoWeave

    列を選び、ファイル一覧を確認して「分割」をクリック。書式はそのまま、ファイルは手元に残ります。

新しいファイルに引き継がれるもの、 引き継がれないもの

引き継がれる

  • フォント、塗りつぶし、罫線、配置
  • 列幅、数値と日付の表示形式
  • 表の上の見出し行（すべてのファイルに）
  • 行の高さ

ベータ版（「詳細設定」で有効化、初期設定はオフ）

  • シートの保護と編集可能なセル
  • ドロップダウンリストとデータの入力規則
  • 条件付き書式

分割と結合の「元のブックから保持するもの」で切り替えます。

引き継がれない

  • ピボットテーブル、グラフ、画像
  • マクロ（結果は通常のXLSX）
  • 数式（Excelが保存した値のみ）

XLSX、XLSM、XLS、XLSB、CSV、TSV、TXT を開けます。分割では、旧形式の XLS（Excel 97–2003）からデータ、表示形式、結合セルを引き継ぎますが、フォント、塗りつぶし、罫線は引き継ぎません。バイナリ形式の XLSB からは値のみです。結合では、XLS、XLSB、またはテキストファイル（CSV、TSV、TXT）が含まれる場合、XLSX のブックの部分も含めて、表全体を書式なしの値として書き込みます。

このプロジェクトについて

RoWeave はひとりの開発者がつくっています。できることは、表の分割、ファイルの結合、CSV から Excel への変換の 3 つです。そのほかの機能は、いただいた声をもとに少しずつ追加しています。

うまく動かないことや足りない機能があれば、 support@roweave.appまでお知らせください。

よくある質問

どこでダウンロードできますか？+

ページ下部の「ダウンロード」から、Windows 用インストーラーと Mac 用 DMG を入手できます。新しいバージョンが出ると、RoWeave がお知らせします。

料金はいくらですか？+

現在、Windows 版・Mac 版の RoWeave は無料です。すべての機能を制限なく使え、登録も広告もありません。

RoWeaveはどのパソコンで使えますか？+

Windows 10・11（64ビット版、x64）と、Apple Silicon（M1以降）搭載でmacOS 12.3以降のMacに対応します。

元のファイルは変更されますか？+

いいえ。RoWeaveは元のファイルを読み込むだけで、上書きはしません。結果は、指定したフォルダーに別のファイルとして保存されます。

書式や数式は残りますか？+

分割では、フォント、塗りつぶし、罫線、列幅、数値の表示形式を引き継ぎます。数式は、Excelがブックに最後に保存した値に置き換わります。数値はそのままですが、データを変更しても再計算されません。結合でも値として書き込み、すべてのソースが XLSX・XLSM のブックであれば書式も引き継ぎます。

引き継がれるもの・引き継がれないもの

大きなファイルも扱えますか？+

大きな CSV は、ファイル全体をメモリに読み込まずに分割して Excel に変換します。上限は 800 万セル（例：40 万行 × 20 列）と 400 万行です。セル内の文字列がとても長い場合は、上限が下がることがあります。行数が Excel のシートの上限（1,048,576 行）を超える場合は、複数のシートに分けることを提案します。分割と結合は表全体をメモリに保持するため、上限はお使いのコンピューターによって変わります。大きなファイルでは警告を表示し、そのまま試すこともできます。

パスワード付きのファイルにも対応していますか？+

XLSX、XLSM、XLSB形式なら開けます。パスワードはアプリで入力し、保存されることはありません。暗号化された旧形式のXLS（Excel 97–2003）には対応していません。分割では、新しいファイルにパスワードを設定することもできます。全ファイル共通でも、ファイルごとに別々でもかまいません。パスワードの一覧は別のファイルに保存されます。

Excelのインストールは必要ですか？+

いいえ。RoWeaveがファイルの読み込みと作成を行います。Excelが必要なのは結果を開くときだけで、ほかの表計算ソフトでもかまいません。

アプリとこのサイトのプライバシー+

アプリはExcelファイルをお使いのパソコン上だけで処理し、その内容をネットワークに送信しません。アプリがインターネットに接続するのは、アップデートの確認（updates.roweave.app、つながらない場合は GitHub）と、クリックしたときに新しいバージョンを GitHub からダウンロードするときだけです。ファイル名や内容は送信されません。自動確認はオフにできます。このサイトには、フォーム、広告、アクセス解析、Cookieはありません。

アプリの「サポートに連絡」は support@roweave.app 宛てのメールを用意するだけです。送信するのはご自身のメールで、RoWeave が何かを送ることはありません。「診断情報を添付」をオンにすると、技術情報（RoWeave とシステムのバージョン、処理の手順と時間、エラーコード、メモリの見積もり）を記録したファイルを保存してメールに添付します。表の内容、パス、パスワードは含まれません。

サイトとダウンロードファイルは GitHub でホストされており、GitHub は IP アドレスなどの接続の技術情報を把握します。support@roweave.app にメールをいただいた場合、アドレスは返信にだけ使います。

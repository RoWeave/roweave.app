無料ベータ 0.13 · Windows 10/11 と macOS 12.3+

Excelを列ごとに分割。 レポートを1つに結合。

RoWeave は、Excel ファイルを列ごとに別々のファイルへ分割し、フォルダー内のレポートを1つの表にまとめます。

無料でダウンロード 使い方 ↓

アップロード不要

RoWeave はお使いのコンピューター上でファイルを処理します。アップデートの自動確認は設定でオフにできます。

Excel に組み込まない

VBA マクロもアドインも使わない、独立したアプリです。Excel がインストールされていなくても使え、Windows では管理者権限なしでインストールできます。

実行前にプランを確認できる

実行する前に、作成されるファイルと引き継がれない要素をRoWeaveが表示します。

ふだん手作業でしている 3つの作業

分割

1つの表 → 値ごとのファイル

「部署」などの列を選びます。RoWeaveが部署ごとにブックを作成し、見出し行、列幅、数値の表示形式、塗りつぶしと文字の色をそのまま引き継ぎます。複数の列を選ぶと、最初の列でサブフォルダーに振り分けます。

「シートごとに別ファイル」モードでは、同じシート内で完結する数式のうち、対応しているものを保持できます。非常に大きなブックには「分割読み込みで分ける」モードがあります。作成したファイルはそのまま ZIP にまとめたり、パスワードをかけたりできます。パスワードは全ファイル共通でも、ファイルごとに別々でも設定でき、一覧は別ファイルに保存されます。

結合

複数のファイル → 1つの表

レポートの入ったフォルダーをドロップします。RoWeaveが各ブックから必要なシートを取り出し、見出しが一致しているか確認して、行を1つの表にまとめます。元のファイル名の列を追加することもできます。パスワード付きのブックも、XLSX、XLSM、XLSB形式なら対応しています。暗号化された旧形式のXLS（Excel 97–2003）は開けません。

CSV → Excel

CSVデータ → 通常のExcelファイル

CSV を XLSX に変換しても、商品コードや取引先コード、口座番号の先頭のゼロはそのまま。長い番号が「1.2E+15」に変わることもありません。

文字コードは RoWeave が自動で判別します。UTF-8 や Shift_JIS にも対応しています。判別に自信がないときは、プレビューを表示して選んでもらいます。大きなデータは少しずつ読み込み、800万セルまで対応します。

使い方

  1. 1

    ファイルをドロップ

    ブック1つでも、複数のファイルでも、フォルダーごとでもかまいません。XLSX、XLSM、XLS、XLSB、CSV、TSV、TXTに対応しています。

  2. 2

    結果を事前に確認

    シートと列を選びます。作成されるファイルの一覧が表示され、引き継がれない要素があれば警告が出ます。

  3. 3

    結果を保存

    新しいファイルは指定したフォルダーに保存されます。元のファイルは変更されず、過去の処理は「履歴」に残ります。

— 引き継がれない

  • ピボットテーブル、グラフ、画像
  • マクロ（結果は通常のXLSX）

数式

数式は通常、ブックに保存されている値に置き換わります。「シートごとに別ファイル」モードでは、そのシート内だけを参照するサポート対象の数式を残せます。制限は実行前にアプリが表示します。

分割での旧形式・バイナリ形式のファイル

旧形式の XLS（Excel 97–2003）からは、データ、数値の表示形式、結合セルを引き継ぎますが、フォント、塗りつぶし、罫線は引き継ぎません。バイナリ形式の XLSB からは値のみです。

結合で形式が混在する場合

ソースに XLS、XLSB、またはテキストファイル（CSV、TSV、TXT）が含まれる場合、結合は XLSX のブックの部分も含めて、表全体を書式なしの値として書き込みます。

よくある質問

Excelファイルを複数のファイルに分割するには？+

「分割」で表を開き、「都市」などの列を選んで実行します。RoWeave はその列の値ごとに別々のファイルを作り、見出し、列幅、書式はそのまま引き継ぎます。実行前に作成されるファイルの一覧を確認できます。

複数のExcelファイルを1つにまとめるには？+

ファイルの入ったフォルダーを「結合」にドロップします。RoWeave は各ブックから必要なシートを取り出し、見出しが一致するか確認して、行を1つの表にまとめます。元のファイル名の列を追加することもできます。

CSVを開くとExcelが先頭のゼロを消すのはなぜ？+

Excel は数字に見える列を数値に変換するため、00123 は 123 になり、長い番号は「1.2E+15」になります。RoWeave で CSV を XLSX に変換すれば、商品コードやID、口座番号は書き出したときのまま残ります。

料金はいくらですか？+

現在、Windows 版・Mac 版の RoWeave は無料です。すべての機能を制限なく使え、登録も広告もありません。

RoWeaveはどのパソコンで使えますか？+

Windows 10・11（64ビット版、x64）と、Apple Silicon（M1以降）搭載でmacOS 12.3以降のMacに対応します。

元のファイルは変更されますか？+

いいえ。RoWeaveは元のファイルを読み込むだけで、上書きはしません。結果は、指定したフォルダーに別のファイルとして保存されます。

書式や数式は残りますか？+

分割では、フォント、塗りつぶし、罫線、列幅、数値の表示形式を引き継ぎます。数式は通常、ブックに保存されている値に置き換わります。「シートごとに別ファイル」モードでは、そのシート内だけを参照するサポート対象の数式を残せます。制限は実行前にアプリが表示します。結合でも値として書き込み、すべてのソースが XLSX・XLSM のブックであれば書式も引き継ぎます。 引き継がれるもの・引き継がれないもの

大きなファイルも扱えますか？+

RoWeave は大きな CSV を、ファイル全体をメモリに読み込まずに少しずつ Excel に変換します。上限は 800 万セル（例：40 万行 × 20 列）と 400 万行です。行数が Excel のシートの上限（1,048,576 行）を超える場合は、複数のシートに分けることを提案します。通常のモードでは、分割と結合の上限はお使いのコンピューターのメモリによって変わります。ブックが大きすぎる場合は、分割が「分割読み込みで分ける」を提案します。このモードには独自の制限があり、実行前に表示されます。

パスワード付きのファイルにも対応していますか？+

XLSX、XLSM、XLSB形式なら開けます。パスワードはアプリで入力し、保存されることはありません。暗号化された旧形式のXLS（Excel 97–2003）には対応していません。分割では、新しいファイルにパスワードを設定することもできます。全ファイル共通でも、ファイルごとに別々でもかまいません。パスワードの一覧は別のファイルに保存されます。

Excelのインストールは必要ですか？+

いいえ。RoWeaveがファイルの読み込みと作成を行います。Excelが必要なのは結果を開くときだけで、ほかの表計算ソフトでもかまいません。

アプリとこのサイトのプライバシー+

アプリはExcelファイルをお使いのパソコン上だけで処理し、その内容をネットワークに送信しません。アプリがインターネットに接続するのは、アップデートの確認（updates.roweave.app、つながらない場合は GitHub）と、クリックしたときに新しいバージョンを GitHub からダウンロードするときだけです。ファイル名や内容は送信されません。自動確認はオフにできます。このサイトには、フォーム、広告、アクセス解析、Cookieはありません。

アプリの「サポートに連絡」は support@roweave.app 宛てのメールを用意するだけです。送信するのはご自身のメールで、RoWeave が何かを送ることはありません。「診断情報を添付」をオンにすると、技術情報（RoWeave とシステムのバージョン、処理の手順と時間、エラーコード、メモリの見積もり）を記録したファイルを保存してメールに添付します。表の内容、パス、パスワードは含まれません。

サイトとダウンロードファイルは GitHub でホストされており、GitHub は IP アドレスなどの接続の技術情報を把握します。support@roweave.app にメールをいただいた場合、アドレスは返信にだけ使います。

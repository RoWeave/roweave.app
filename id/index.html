Pisahkan Excel per kolom. Gabungkan laporan jadi satu.

RoWeave memisahkan file Excel per kolom menjadi file-file terpisah dan menggabungkan laporan dari satu folder menjadi satu tabel.

Unduh gratis Cara kerja ↓

Tidak ada yang diunggah

RoWeave memproses file di komputer Anda. Pemeriksaan pembaruan otomatis bisa dimatikan di pengaturan.

Tidak dipasang di dalam Excel

Aplikasi terpisah tanpa makro VBA atau add-in. Excel tidak perlu terpasang, dan di Windows aplikasi ini dipasang tanpa hak administrator.

Lihat rencananya sebelum dijalankan

Sebelum apa pun dijalankan, RoWeave menunjukkan file apa yang akan Anda dapatkan dan apa yang tidak ikut terbawa.

Tiga pekerjaan yang biasanya dikerjakan manual

Pisahkan

Satu lembar → satu file untuk setiap nilai

Pilih kolom, misalnya “Departemen”. RoWeave membuat satu buku kerja per departemen dengan tetap mempertahankan baris header, lebar kolom, format angka, serta warna isian dan font. Pilih beberapa kolom, dan kolom pertama menentukan subfolder.

Ada juga mode “Setiap lembar sebagai file terpisah” (bisa mempertahankan rumus yang didukung dalam lembar yang sama) dan mode “Pisahkan per bagian” untuk buku kerja yang sangat besar. File hasil bisa langsung dikemas ke ZIP atau diberi kata sandi: satu untuk semua atau berbeda untuk setiap file, dengan daftar kata sandi di file terpisah.

Gabungkan

Banyak file → satu lembar

Masukkan satu folder laporan. RoWeave mengambil lembar yang tepat dari setiap buku kerja, memeriksa bahwa header-nya cocok, lalu menumpuk barisnya menjadi satu tabel. Anda juga bisa menambahkan kolom berisi nama file sumber. Buku kerja XLSX, XLSM, dan XLSB yang dilindungi kata sandi juga bisa diproses; file XLS lama (Excel 97–2003) yang dienkripsi tidak dapat dibuka.

CSV → Excel

Ekspor CSV → file Excel yang rapi

Konversi CSV ke XLSX dengan tetap mempertahankan angka nol di depan pada kode produk, ID, dan nomor rekening, agar angka panjang tidak berubah menjadi “1,2E+15”.

RoWeave mendeteksi pengodean sendiri, termasuk UTF-8 dan Windows-1252. Jika tidak yakin, RoWeave menampilkan pratinjau dan meminta Anda memilih. Ekspor besar dibaca bertahap, hingga 8 juta sel.

Cara kerja

  1. 1

    Masukkan file Anda

    Satu buku kerja, beberapa file, atau satu folder penuh. Mendukung XLSX, XLSM, XLS, XLSB, CSV, TSV, dan TXT.

  2. 2

    Periksa hasilnya

    Pilih lembar dan kolom. RoWeave menampilkan daftar file yang akan dibuat dan memperingatkan Anda jika ada yang tidak ikut terbawa.

  3. 3

    Simpan hasilnya

    File baru disimpan di folder pilihan Anda. File asli tidak tersentuh, dan proses sebelumnya tersimpan di Riwayat.

Apa yang ikut terbawa ke file baru dan apa yang tidak

✓ Dipertahankan

  • Font, warna isian, border, perataan
  • Lebar kolom, format angka dan tanggal
  • Baris header di atas tabel di setiap file
  • Tinggi baris

β Beta, aktifkan di Pengaturan lanjutan

Nonaktif secara default. Di bagian “Yang dipertahankan dari buku kerja sumber” pada Pisahkan dan Gabungkan.

  • Perlindungan lembar dan sel yang dapat diedit
  • Daftar menurun dan validasi data
  • Pemformatan bersyarat

— Tidak dibawa

  • PivotTable, bagan, gambar
  • Makro: hasilnya XLSX biasa

Rumus

Rumus biasanya diganti dengan nilai yang tersimpan di buku kerja. Dalam mode “Setiap lembar sebagai file terpisah”, rumus yang didukung dan hanya merujuk ke lembarnya sendiri bisa dipertahankan. Aplikasi menampilkan batasannya sebelum dijalankan.

File lama dan biner di Pisahkan

Dari XLS (Excel 97–2003), Pisahkan membawa data, format angka, dan sel gabungan, tetapi tidak font, warna isian, atau border; dari XLSB biner, hanya nilai.

Sumber campuran di Gabungkan

Jika sumbernya mencakup XLS, XLSB, atau file teks (CSV, TSV, TXT), Gabungkan menulis seluruh tabel sebagai nilai tanpa format, termasuk bagian dari buku kerja XLSX.

Pertanyaan umum

Bagaimana cara memisahkan file Excel menjadi beberapa file?+

Buka lembar di Pisahkan, pilih kolom seperti “Kota”, lalu jalankan. RoWeave membuat satu file untuk setiap nilai di kolom itu, dengan header, lebar kolom, dan format yang sama. Anda melihat daftar file sebelum apa pun dijalankan.

Bagaimana cara menggabungkan beberapa file Excel menjadi satu?+

Seret folder berisi file ke Gabungkan. RoWeave mengambil lembar yang tepat dari setiap buku kerja, memeriksa apakah header cocok, lalu menyusun barisnya menjadi satu tabel. Anda bisa menambahkan kolom berisi nama file sumber.

Mengapa Excel menghapus angka nol di depan saat membuka CSV?+

Excel mengubah kolom yang tampak seperti angka menjadi angka, sehingga 00123 menjadi 123 dan nomor panjang berubah menjadi “1,2E+15”. Ubah CSV ke XLSX dengan RoWeave: kode produk, ID, dan nomor rekening tetap seperti saat diekspor.

Berapa harganya?+

Saat ini RoWeave gratis untuk Windows dan Mac: semua fitur, tanpa batasan, tanpa pendaftaran, dan tanpa iklan.

Di komputer apa RoWeave berjalan?+

Windows 10 dan 11 (64-bit, x64), serta Mac dengan Apple Silicon (M1 atau lebih baru) yang menjalankan macOS 12.3 atau lebih baru.

Apakah file asli saya akan berubah?+

Tidak. RoWeave hanya membaca file sumber Anda dan tidak pernah menimpanya. Hasil disimpan terpisah, di folder yang Anda pilih.

Apakah format dan rumus dipertahankan?+

Pisahkan mempertahankan font, warna isian, border, lebar kolom, dan format angka. Rumus biasanya diganti dengan nilai yang tersimpan di buku kerja. Dalam mode “Setiap lembar sebagai file terpisah”, rumus yang didukung dan hanya merujuk ke lembarnya sendiri bisa dipertahankan; aplikasi menampilkan batasannya sebelum dijalankan. Gabungkan juga menulis nilai, dan mempertahankan format bila semua sumber adalah buku kerja XLSX atau XLSM. Apa yang dipertahankan dan apa yang tidak

Apakah bisa menangani file besar?+

RoWeave mengonversi CSV besar ke Excel sebagian demi sebagian, tanpa memuat seluruh file ke memori. Batasnya 8 juta sel (misalnya 400.000 baris × 20 kolom) dan 4 juta baris. Jika baris lebih banyak daripada kapasitas satu lembar Excel (1.048.576), RoWeave menawarkan untuk membaginya ke beberapa lembar. Dalam mode biasa, batas Pisahkan dan Gabungkan bergantung pada memori komputer. Jika buku kerja terlalu besar, Pisahkan menawarkan mode “Pisahkan per bagian” dengan batasan tersendiri, yang ditampilkan sebelum dijalankan.

Bagaimana dengan file yang dilindungi kata sandi?+

Buku kerja XLSX, XLSM, dan XLSB bisa dibuka: Anda memasukkan kata sandi di aplikasi, dan kata sandi itu tidak pernah disimpan. File terenkripsi dalam format XLS lama (Excel 97–2003) tidak dapat dibuka. Pisahkan juga dapat memberi kata sandi pada file baru: satu kata sandi untuk semua, atau berbeda untuk tiap file, dengan daftarnya disimpan ke file terpisah.

Apakah Excel harus terinstal?+

Tidak. RoWeave membaca dan menulis file sendiri. Untuk membuka hasilnya, Anda hanya perlu Excel atau aplikasi spreadsheet lain.

Aplikasi memproses file Excel hanya di komputer Anda dan tidak pernah mengirim isinya melalui jaringan. Aplikasi hanya terhubung ke internet untuk memeriksa pembaruan (updates.roweave.app, atau GitHub jika gagal) dan, saat Anda mengklik, untuk mengunduh versi baru dari GitHub. Tidak ada nama atau isi file yang dikirim, dan pemeriksaan otomatis dapat dimatikan. Situs ini tidak memiliki formulir, iklan, pelacak, atau cookie.

“Hubungi dukungan” di aplikasi hanya menyiapkan email ke support@roweave.app: Anda sendiri yang mengirimnya dari email Anda, RoWeave tidak mengirim apa pun. Jika “Lampirkan diagnostik” dicentang, aplikasi menyimpan file berisi data teknis (versi RoWeave dan sistem, langkah dan waktu proses, kode kesalahan, perkiraan memori) lalu melampirkannya ke email. File itu tidak berisi isi tabel, jalur, atau kata sandi.

Situs dan file unduhan di-hosting di GitHub, yang melihat data koneksi teknis seperti alamat IP Anda. Jika Anda mengirim email ke support@roweave.app, alamat Anda hanya dipakai untuk membalas.

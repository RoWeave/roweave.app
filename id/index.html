Unduh

Pisahkan Excel per kolom. Gabungkan laporan jadi satu.

RoWeave membagi satu lembar menjadi buku kerja terpisah, satu untuk setiap cabang, departemen, atau tenaga penjual. Setiap buku kerja memiliki header, lebar kolom, dan format angka yang sama. Bisa juga sebaliknya: menggabungkan satu folder laporan menjadi satu tabel.

Jika Anda mengerjakan ini manual setiap bulan

Filter, salin, file baru, tempel, rapikan lebar kolom. Lalu ulangi untuk setiap departemen. Atau makro yang hanya dipahami pembuatnya.

  • Keuangan & akuntansi

    Kirim laporan ke setiap cost center

    Satu laporan seluruh perusahaan → satu file per cost center, dengan header dan format angka yang sama.

  • HR

    Beri setiap manajer hanya timnya sendiri

    Daftar karyawan → satu file per departemen, masing-masing dengan kata sandi sendiri. RoWeave menyimpan kata sandi ke daftar terpisah.

  • Logistik & gudang

    Gabungkan laporan gudang jadi satu lembar

    30 file dari berbagai lokasi → satu tabel. Setiap baris bisa memuat nama file asalnya.

  • Operasional penjualan

    Kirim target vs. realisasi ke setiap tenaga penjual

    Ekspor CRM dengan kolom Wilayah dan Tenaga penjual → satu folder per wilayah, berisi satu file untuk setiap tenaga penjual.

  • Ekspor ERP & bank

    Buka CSV tanpa kehilangan angka nol di depan

    CSV → XLSX, dengan kode produk, NPWP, dan nomor rekening persis seperti saat diekspor.

  • Sekolah & universitas

    Pisahkan daftar nama per kelas atau kelompok

    Satu daftar induk → satu file per kelompok. Nanti, gabungkan kembali file dari para guru menjadi satu buku kerja.

Tiga pekerjaan yang biasanya dikerjakan manual

Sebelum apa pun dijalankan, RoWeave menunjukkan file apa yang akan Anda dapatkan dan apa yang tidak ikut terbawa.

Pisahkan

Daftar gaji→satu file per departemen

Selengkapnya

Pilih kolom, misalnya “Departemen”. RoWeave membuat satu buku kerja per departemen dengan tetap mempertahankan baris header, lebar kolom, format angka, serta warna isian dan font. Pilih beberapa kolom, dan kolom pertama menentukan subfolder. Setiap file bisa diberi kata sandi sendiri.

Gabungkan

Banyak file → satu lembar

30 laporan cabang→satu lembar

Selengkapnya

Masukkan satu folder laporan. RoWeave mengambil lembar yang tepat dari setiap buku kerja, memeriksa bahwa header-nya cocok, lalu menumpuk barisnya menjadi satu tabel. Anda juga bisa menambahkan kolom berisi nama file sumber. Buku kerja XLSX, XLSM, dan XLSB yang dilindungi kata sandi juga bisa diproses; file XLS lama (Excel 97–2003) yang dienkripsi tidak dapat dibuka.

CSV → Excel

Ekspor CSV → file Excel yang rapi

Ekspor ERP→XLSX, nol tetap ada

Selengkapnya

Kode produk dan ID tetap mempertahankan angka nol di depan, dan angka panjang tidak berubah menjadi “1,2E+15”. RoWeave mendeteksi sendiri pengodean file: UTF-8 dan UTF-16, Windows-1252 dan Windows-1250 untuk bahasa-bahasa Eropa, Windows-1254 untuk bahasa Turki, Windows-1258 untuk bahasa Vietnam, Windows-1251 dan KOI8-R untuk Sirilik, Shift_JIS untuk bahasa Jepang, GBK/GB18030 untuk bahasa Tionghoa, serta CP949 untuk bahasa Korea. Jika tidak yakin, RoWeave menampilkan pratinjau dan bertanya. Ekspor besar dibaca bertahap, hingga 8 juta sel.

Cara kerja

  1. 1

    Masukkan file Anda

    Satu buku kerja, beberapa file, atau satu folder penuh. Mendukung XLSX, XLSM, XLS, XLSB, CSV, TSV, dan TXT.

  2. 2

    Periksa hasilnya

    Pilih lembar dan kolom. RoWeave menampilkan daftar file yang akan dibuat dan memperingatkan Anda jika ada yang tidak ikut terbawa.

  3. 3

    Simpan hasilnya

    File baru disimpan di folder pilihan Anda. File asli tidak tersentuh, dan proses sebelumnya tersimpan di Riwayat.

Cara yang biasa dipakai

  • Manual

    Filter → salin → file baru → tempel → rapikan format. Ulangi 40 kali. Salah sedikit saja, dan ada yang menerima data yang bukan miliknya.

  • Makro VBA

    Jalan selama pembuatnya masih ada. Sering gagal di Mac, dan banyak perusahaan memblokir file berisi makro.

  • Layanan online

    Data gaji atau data pelanggan harus diunggah ke server milik orang lain.

  • RoWeave

    Pilih kolom, tinjau daftar file, klik Pisahkan. Format tetap utuh, file tetap bersama Anda.

Tidak dibawa

  • PivotTable, bagan, gambar
  • Makro: hasilnya XLSX biasa
  • Rumus: Anda mendapatkan nilai yang terakhir disimpan Excel

Membuka XLSX, XLSM, XLS, XLSB, CSV, TSV, dan TXT. Dari XLS lama (Excel 97–2003), Pisahkan membawa data, format angka, dan sel gabungan, tetapi tidak font, warna isian, atau border; dari XLSB biner, hanya nilai. Jika salah satu sumber Gabungkan adalah XLS, XLSB, atau file teks (CSV, TSV, TXT), seluruh tabel ditulis sebagai nilai tanpa format, termasuk bagian dari buku kerja XLSX.

Tentang proyek

RoWeave dibuat oleh satu pengembang. Aplikasi ini melakukan tiga hal: memisahkan tabel, menggabungkan file, dan mengubah CSV menjadi Excel. Fitur lain saya tambahkan sedikit demi sedikit berdasarkan masukan.

Jika ada yang tidak berfungsi atau kurang, tulis ke support@roweave.app.

Pertanyaan umum

Di mana mengunduhnya?+

Di bagian bawah halaman, pada “Unduh”: penginstal untuk Windows dan image DMG untuk Mac. RoWeave akan memberi tahu saat ada versi baru.

Berapa harganya?+

Saat ini RoWeave gratis untuk Windows dan Mac: semua fitur, tanpa batasan, tanpa pendaftaran, dan tanpa iklan.

Di komputer apa RoWeave berjalan?+

Windows 10 dan 11 (64-bit, x64), serta Mac dengan Apple Silicon (M1 atau lebih baru) yang menjalankan macOS 12.3 atau lebih baru.

Apakah file asli saya akan berubah?+

Tidak. RoWeave hanya membaca file sumber Anda dan tidak pernah menimpanya. Hasil disimpan terpisah, di folder yang Anda pilih.

Apakah format dan rumus dipertahankan?+

Pisahkan mempertahankan font, warna isian, border, lebar kolom, dan format angka. Rumus diganti dengan nilai yang terakhir disimpan Excel di buku kerja: angkanya tetap sama, tetapi tidak dihitung ulang saat data berubah. Gabungkan juga menulis nilai, dan mempertahankan format bila semua sumber adalah buku kerja XLSX atau XLSM.

Apa yang dipertahankan dan apa yang tidak

Apakah bisa menangani file besar?+

RoWeave mengonversi CSV besar ke Excel sebagian demi sebagian, tanpa memuat seluruh file ke memori. Batasnya 8 juta sel (misalnya 400.000 baris × 20 kolom) dan 4 juta baris; jika teks di sel sangat panjang, batasnya bisa lebih rendah. Jika baris lebih banyak daripada kapasitas satu lembar Excel (1.048.576), RoWeave menawarkan untuk membaginya ke beberapa lembar. Pisahkan dan Gabungkan menyimpan seluruh tabel di memori, jadi batasnya bergantung pada komputer: untuk file besar, RoWeave akan memperingatkan dan menawarkan untuk tetap mencoba.

Bagaimana dengan file yang dilindungi kata sandi?+

Buku kerja XLSX, XLSM, dan XLSB bisa dibuka: Anda memasukkan kata sandi di aplikasi, dan kata sandi itu tidak pernah disimpan. File terenkripsi dalam format XLS lama (Excel 97–2003) tidak dapat dibuka. Pisahkan juga dapat memberi kata sandi pada file baru: satu kata sandi untuk semua, atau berbeda untuk tiap file, dengan daftarnya disimpan ke file terpisah.

Apakah Excel harus terinstal?+

Tidak. RoWeave membaca dan menulis file sendiri. Untuk membuka hasilnya, Anda hanya perlu Excel atau aplikasi spreadsheet lain.

Privasi di aplikasi dan di situs ini+

Aplikasi memproses file Excel hanya di komputer Anda dan tidak pernah mengirim isinya melalui jaringan. Aplikasi hanya terhubung ke internet untuk memeriksa pembaruan (updates.roweave.app, atau GitHub jika gagal) dan, saat Anda mengklik, untuk mengunduh versi baru dari GitHub. Tidak ada nama atau isi file yang dikirim, dan pemeriksaan otomatis dapat dimatikan. Situs ini tidak memiliki formulir, iklan, pelacak, atau cookie.

“Hubungi dukungan” di aplikasi hanya menyiapkan email ke support@roweave.app: Anda sendiri yang mengirimnya dari email Anda, RoWeave tidak mengirim apa pun. Jika “Lampirkan diagnostik” dicentang, aplikasi menyimpan file berisi data teknis (versi RoWeave dan sistem, langkah dan waktu proses, kode kesalahan, perkiraan memori) lalu melampirkannya ke email. File itu tidak berisi isi tabel, jalur, atau kata sandi.

Situs dan file unduhan di-hosting di GitHub, yang melihat data koneksi teknis seperti alamat IP Anda. Jika Anda mengirim email ke support@roweave.app, alamat Anda hanya dipakai untuk membalas.

通常要手动完成的 三件事

拆分

一张表 → 每个值一个文件

选择一列，比如“部门”。RoWeave 为每个部门创建一个工作簿，表头行、列宽、数字格式以及填充色和字体颜色都与原表一致。如果选择多列，会按第一列把文件放进子文件夹。

“每个工作表一个文件”模式可保留受支持且仅引用本工作表的公式。特别大的工作簿可以用“分段拆分”模式。生成的文件可以直接打包成 ZIP，或加上密码：所有文件共用一个密码，或每个文件各用一个，密码列表会保存到单独的文件中。

合并

多个文件 → 一张表

把装有报表的文件夹拖进来。RoWeave 从每个工作簿中取出所需的工作表，核对表头是否一致，再把所有行汇总到一张表里。还可以添加一列，记录来源文件名。带密码的 XLSX、XLSM 和 XLSB 工作簿也能处理；加密的旧版 XLS（Excel 97–2003）文件无法打开。

CSV → Excel

CSV 导出文件 → 规范的 Excel 文件

把 CSV 转换为 XLSX，商品编码、各类编号和账号开头的 0 都会保留，长数字也不会变成“1.2E+15”。

RoWeave 会自动识别编码，包括 UTF-8 和 GBK/GB18030。拿不准时，会显示预览并让您选择。较大的导出文件会分块读取，最多 800 万个单元格。

公式

公式通常会替换为工作簿中保存的值。在“每个工作表一个文件”模式下，可以保留只引用本工作表的受支持公式。相关限制会在运行前显示。

拆分旧版和二进制文件

拆分旧版 XLS（Excel 97–2003）时，会保留数据、数字格式和合并单元格，但不保留字体、填充和边框；二进制 XLSB 只保留值。

合并时来源格式混杂

如果来源中有 XLS、XLSB 或文本文件（CSV、TSV、TXT），合并会把整张表（包括来自 XLSX 工作簿的部分）以不带格式的数值写入。

常见问题

如何把一个 Excel 文件拆分成多个文件？+

在“拆分”中打开表格，选择一列（例如“城市”）后运行。RoWeave 会为该列的每个值生成一个文件，表头、列宽和格式保持不变。运行前就能看到将要生成的文件列表。

如何把多个 Excel 文件合并成一个？+

把装有文件的文件夹拖到“合并”中。RoWeave 会从每个工作簿取出正确的工作表，检查表头是否一致，再把各行合并成一张表。还可以添加一列，记录来源文件名。

为什么用 Excel 打开 CSV 时开头的 0 不见了？+

Excel 会把看起来像数字的列转换成数字，所以 00123 变成 123，长编号变成“1.2E+15”。用 RoWeave 把 CSV 转成 XLSX，商品编码、证件号和账号都会保持导出时的样子。

价格是多少？+

目前，适用于 Windows 和 Mac 的 RoWeave 免费：全部功能，不限次数，无需注册，也没有广告。

RoWeave 能在哪些电脑上运行？+

Windows 10 和 11（64 位，x64），以及搭载 Apple Silicon（M1 或更新）、运行 macOS 12.3 或更高版本的 Mac。

会改动我的原文件吗？+

不会。RoWeave 只读取源文件，从不覆盖它们。结果另行保存到你选择的文件夹中。

格式和公式会保留吗？+

拆分会保留字体、填充、边框、列宽和数字格式。公式通常会替换为工作簿中保存的值。在“每个工作表一个文件”模式下，可以保留只引用本工作表的受支持公式；相关限制会在运行前显示。合并同样写入数值，当所有来源都是 XLSX 或 XLSM 工作簿时，会保留格式。 哪些会保留，哪些不会

能处理大文件吗？+

RoWeave 会分块把大型 CSV 转换为 Excel，不会把整个文件读入内存。上限为 800 万个单元格（例如 40 万行 × 20 列）和 400 万行。如果行数超过一个 Excel 工作表的容量（1,048,576 行），RoWeave 会建议分到多个工作表中。在普通模式下，拆分和合并的上限取决于电脑内存。如果工作簿太大，拆分会建议使用“分段拆分”模式，该模式有单独的限制，会在运行前显示。

带密码的文件怎么办？+

XLSX、XLSM 和 XLSB 工作簿可以正常打开：在应用中输入密码即可，密码不会被保存。加密的旧版 XLS（Excel 97–2003）文件不受支持。拆分还能为新文件设置密码：所有文件共用一个，或每个文件各用一个，密码清单另存为单独的文件。

需要安装 Excel 吗？+

不需要。RoWeave 自己读取和生成文件。只有打开结果时才需要 Excel，用其他电子表格软件也可以。

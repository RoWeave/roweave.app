通常要手动完成的 三件事

开始处理之前，RoWeave 会先告诉你将生成哪些文件，以及哪些内容无法保留。

拆分

一张表 → 每个值一个文件

全公司工资表→每个部门一个文件

了解详情

选择一列，比如“部门”。RoWeave 为每个部门创建一个工作簿，表头行、列宽、数字格式以及填充色和字体颜色都与原表一致。如果选择多列，会按第一列把文件放进子文件夹。每个文件还可以各自设置密码。

合并

多个文件 → 一张表

30 份分公司报表→一张汇总表

了解详情

把装有报表的文件夹拖进来。RoWeave 从每个工作簿中取出所需的工作表，核对表头是否一致，再把所有行汇总到一张表里。还可以添加一列，记录来源文件名。带密码的 XLSX、XLSM 和 XLSB 工作簿也能处理；加密的旧版 XLS（Excel 97–2003）文件无法打开。

CSV → Excel

CSV 导出文件 → 规范的 Excel 文件

财务导出数据→保留 0 的 XLSX

了解详情

商品编码和各类编号开头的 0 不会丢失，长数字也不会变成“1.2E+15”。文件编码会自动识别（UTF-8、UTF-16、简体中文 GBK/GB18030、日文 Shift_JIS、韩文 CP949、欧洲语言的 Windows-1252 和 Windows-1250、土耳其语的 Windows-1254、越南语的 Windows-1258、西里尔文的 Windows-1251 和 KOI8-R）；拿不准时会显示预览并询问您。较大的导出文件也会分块读取，最多 800 万个单元格。

使用方式

  1. 1

    拖入文件

    一个工作簿、几个文件或整个文件夹都可以。支持 XLSX、XLSM、XLS、XLSB、CSV、TSV 和 TXT。

  2. 2

    确认结果

    选择工作表和列。RoWeave 会预先列出将要生成的文件；如果有内容无法保留，也会提醒你。

  3. 3

    保存结果

    新文件保存在你选择的文件夹中。原文件保持不变，历次操作都记录在“历史记录”里。

  • 列宽、数字和日期格式
  • 表格上方的表头行，每个文件都有
  • 行高

支持 XLSX、XLSM、XLS、XLSB、CSV、TSV 和 TXT。拆分时，旧版 XLS（Excel 97–2003）会保留数据、数字格式和合并单元格，但不保留字体、填充和边框；二进制 XLSB 只导入值。合并时，只要来源中有 XLS、XLSB 或文本文件（CSV、TSV、TXT），整张表（包括来自 XLSX 工作簿的部分）都会以不带格式的数值写入。

常见问题

在哪里下载？+

在页面底部的“下载”区域：Windows 安装程序和 Mac 的 DMG 映像。有新版本时，RoWeave 会通知你。

价格是多少？+

目前，适用于 Windows 和 Mac 的 RoWeave 免费：全部功能，不限次数，无需注册，也没有广告。

RoWeave 能在哪些电脑上运行？+

Windows 10 和 11（64 位，x64），以及搭载 Apple Silicon（M1 或更新）、运行 macOS 12.3 或更高版本的 Mac。

会改动我的原文件吗？+

不会。RoWeave 只读取源文件，从不覆盖它们。结果另行保存到你选择的文件夹中。

格式和公式会保留吗？+

拆分会保留字体、填充、边框、列宽和数字格式。公式会替换为 Excel 最后一次保存在工作簿中的值：数字不变，但数据改动后不会重新计算。合并同样写入数值，当所有来源都是 XLSX 或 XLSM 工作簿时，会保留格式。

哪些会保留，哪些不会

能处理大文件吗？+

RoWeave 会分段把大型 CSV 转换为 Excel，不会把整个文件读入内存。上限为 800 万个单元格（例如 40 万行 × 20 列）和 400 万行；如果单元格里的文本很长，上限可能更低。如果行数超过一个 Excel 工作表的容量（1,048,576 行），RoWeave 会建议分到多个工作表中。拆分和合并会把整张表读入内存，所以上限取决于你的电脑：文件较大时，RoWeave 会提示你，并允许你仍然尝试。

带密码的文件怎么办？+

XLSX、XLSM 和 XLSB 工作簿可以正常打开：在应用中输入密码即可，密码不会被保存。加密的旧版 XLS（Excel 97–2003）文件不受支持。拆分还能为新文件设置密码：所有文件共用一个，或每个文件各用一个，密码清单另存为单独的文件。

需要安装 Excel 吗？+

不需要。RoWeave 自己读取和生成文件。只有打开结果时才需要 Excel，用其他电子表格软件也可以。

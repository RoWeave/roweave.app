Privacy Policy

Version 2, October 17, 2026. Covers the RoWeave app 0.11.9 and later, the roweave.app website and emails to support. The Russian text is the original; this is its translation.

In short

  • RoWeave processes your Excel and CSV files only on your computer. Tables, file names, paths and passwords are never sent anywhere.
  • The app has no analytics, telemetry, ads, automatic crash reports or accounts.
  • The app goes online only to check for updates and, when you click, to download one. The automatic check can be turned off.
  • The website has no forms, ads, trackers or cookies.
  • We only receive personal data if you email support yourself.

Who is responsible

RoWeave is made by one developer, who is also responsible for the data handling described here. For any question about your data, email support@roweave.app.

What stays on your computer

The app creates this data for its own work. The developer has no access to it.

  • Run history. Up to the 200 most recent runs, no older than 90 days; older entries are removed automatically. An entry holds the date, tool, outcome, path to the result folder or file and to a saved ZIP, source file name, sheet name, column names, file count and the settings for “Repeat with a new file”. No cell values or passwords. A run interrupted with an unknown outcome stays until “Clear history”.
  • Folder permissions and completion journal. Paths to folders you chose and internal markers, so results can be saved and shown safely.
  • Settings. Theme, language, default results folder, result form (folder or ZIP), check for updates at launch, dismissed hints and the version postponed with “Later”.
  • Support log. Up to 96 events, no older than 90 days: tool, stage, error code, time, counters, memory estimates and the computer’s free memory, update check and download events. No file names, paths, passwords or contents. It goes into a diagnostics file only when you save one.
  • Copies of damaged data. If an internal data file turns out to be damaged, the app sets aside a copy marked corrupt next to its other data and never deletes it itself. It may contain the same as the history.
  • Your results. Files in the folder you chose and a hidden helper file .output-workspace-run.json in the run folder.

To suggest closing other programs when memory runs low, the app checks how much of the computer’s memory is free right now. That number stays on your computer and can only end up in a diagnostics file. The app does not read the list of running programs.

Workbook passwords, including a list pasted from Excel, are used only in memory during the operation. The result password list is written to disk only if you click “Save…”, as a plain text file in a place you choose. Keep it secret.

If a workbook is in OneDrive or iCloud Drive, your system or the cloud client downloads it, not RoWeave. Results in a synced folder are uploaded by that service.

Updates

This applies to the version downloaded from the website. Versions from the Microsoft Store and the Mac App Store have no update module: the app does not go online, and the store installs updates.

  • The automatic check runs once, a few seconds after launch. Turn it off in Settings → Updates → Check at launch. You can check manually with “Check for updates”.
  • The app gets the description of the latest version from updates.roweave.app (Cloudflare), or from github.com if that does not answer within 15 seconds.
  • The request address contains your system and architecture, for example darwin-aarch64 or windows-x86_64. Your current RoWeave version is not sent. Like any server, Cloudflare and GitHub see your IP address, the request time and technical headers.
  • The update file itself is downloaded from GitHub, only after you click. The app checks its signature before installing.
  • On Windows, the installer copy in the temporary folder is removed at the next launch.
  • The “Open roweave.app” button, shown when an update downloads slowly, opens the website in your browser.

File names and contents, paths, passwords, history and diagnostics are not part of these requests. There is no persistent device ID.

If you contact support

“Contact support” only prepares an email. RoWeave sends nothing itself and makes no network request for this.

  • “Open mail” creates a draft in your mail app: the address support@roweave.app, a subject with the RoWeave version and system name, and a short text template.
  • “Use webmail” opens the new-message page of the service you pick in your browser (depending on the language: Gmail, Outlook.com, Yandex Mail, Mail.ru). The subject and template are passed in that page’s address, so the mail service receives them when the page opens, and the address stays in your browser history.
  • “Attach diagnostics” (on by default) saves a diagnostics file to Downloads and attaches it to the draft or shows it in Finder or File Explorer. If Downloads is not available, the file goes to a temporary RoWeave folder and is removed from there after 7 days. The app does not remove it from Downloads. The file is also created by “Copy address and text”.

What the diagnostics file contains. RoWeave version and build time, system and architecture, steps and timings, error codes including system ones, counters (rows, files, sizes), memory estimates for the workbook, the computer’s total and free memory, whether the tip to close other programs was shown, the size of part of the workbook in megabytes if it was rejected as too large, the sheet’s position number, update events, a session number and, for an internal error, the location in RoWeave’s code. No table contents, file names, paths or passwords. “Save diagnostics…” creates the same file.

What the developer receives. When you send an email, we receive your address, your sender name if your mail shows one, the text and attachments. We use them only to reply and solve the problem. Legal basis: your request. Emails are stored in Apple iCloud Mail and deleted one year after the last message in the conversation. We do not sell or share them, except with the mail services they pass through.

Please do not send real workbooks with personal or confidential data. An anonymized sample is usually enough.

The roweave.app website

  • The website has no forms, ads, trackers, cookies, external scripts or fonts.
  • The website is hosted on GitHub Pages, and the download files are on GitHub too. GitHub sees technical request data: IP address, time, page and User-Agent. Cloudflare provides DNS for the domain; site traffic does not pass through it.
  • The page language follows your browser settings and is not stored anywhere. The theme choice is not stored either.
  • The website is connected to Google Search Console and Yandex Webmaster through a DNS record and a verification file. Their code is not on the pages, and they receive no visitor data from the website.

Installation and the operating system

  • If Windows has no Microsoft Edge WebView2, the installer runs Microsoft’s bootstrapper, which downloads this component from Microsoft’s servers. This does not happen when RoWeave updates.
  • Windows SmartScreen and Microsoft Defender, and Gatekeeper on the Mac, may check the installer and the app with Microsoft or Apple. That is the system, not RoWeave.

AI assistants and automation (macOS)

This feature is off by default and not available in the Mac App Store version. If you turn it on, programs running under your user account on this computer can open files you name and save results through a local socket, not the network. They receive the operation’s paths and file names and, with structure sharing on, sheet and column names. Data rows and passwords are never shared. If you connect a cloud AI assistant, its provider may receive this information under its own terms. Access ends when you close the app.

Who receives data and where

  • Apple (iCloud Mail): emails to support.
  • GitHub: the website, download and update files, the fallback update check address.
  • Cloudflare: the main update check address and the domain’s DNS.
  • Your mail service: emails you send.
  • Microsoft Store and Mac App Store, if you install RoWeave from there: under the store’s terms.

These companies have servers in the United States and other countries, so data may be transferred outside your country. They keep server logs under their own privacy policies.

Your rights

You can ask what data we hold about you, have it corrected or deleted, restrict or object to its processing, get a copy of your emails and withdraw consent. Email support@roweave.app; we reply within 10 working days. You can also complain to your country’s data protection authority (in Russia, Roskomnadzor).

Giving us data is optional: the app works without it. There is no automated decision-making or profiling.

How to delete data on your computer

  1. In the app: History → “Clear history”. Your Excel files remain. This does not remove corrupt copies, settings, the support log or the default folder.
  2. Windows, website version: when uninstalling from Apps, check the option to delete the application data (unchecked by default). This removes %APPDATA%\app.roweave.desktop and %LOCALAPPDATA%\app.roweave.desktop. Otherwise they stay, and you can delete them by hand.
  3. macOS: after quitting the app, delete ~/Library/Application Support/app.roweave.desktop, ~/Library/WebKit/app.roweave.desktop, ~/Library/Caches/app.roweave.desktop and ~/Library/Preferences/app.roweave.desktop.plist. For the Mac App Store version: ~/Library/Containers/app.roweave.desktop. Deleting RoWeave.app does not touch these folders.
  4. The Microsoft Store version keeps its data in its own package folder, and Windows removes it together with the app.
  5. Diagnostics files in Downloads, your results and password lists are where you saved them. Delete them yourself.

Security

Your tables never leave your computer. The website and updates work only over HTTPS, update files are signed, and the app checks the signature before installing. Only the developer has access to the support mailbox.

Children

RoWeave is not made specifically for children and collects no data about anyone. If you are under 16, please contact support together with a parent.

Changes

If the app starts handling data differently, for example with a new network feature, we will update this page and its version date before that release and mention the change in the release notes. Version 2 (RoWeave 0.11.10): the diagnostics file gained free memory, the close-programs tip and the size of a workbook that is too large; the Microsoft Store version was added. Previous versions stay in the public history of the RoWeave/roweave.app repository.

Three jobs that usually get done by hand

01

Split

Split an Excel file into multiple files by column

Payroll → one file per department

Choose a column such as “Department”. RoWeave creates one workbook per department, keeping the header rows, column widths, number formats, and fill and font colors. Pick several columns and the first one sets the subfolders. Each file can get its own password.

There’s also an “Each sheet as a separate file” mode. The new files can go straight into a ZIP or get passwords: one for all or a different one for each, with the list saved to a separate file.

02

Combine

Merge Excel files into one

30 branch reports → one sheet

Drop in a folder of reports. RoWeave takes the right sheet from each workbook, checks that the headers match and stacks the rows into one table. Optionally add a column with the source file name. Password-protected XLSX, XLSM and XLSB workbooks work too; encrypted legacy XLS files (Excel 97–2003) can’t be opened.

03

CSV → Excel

CSV to Excel converter that keeps leading zeros

ERP or bank export → XLSX, zeros kept

Convert CSV to XLSX and keep the leading zeros in product codes, IDs and account numbers, so long numbers don’t turn into “1.2E+15”.

RoWeave detects the encoding on its own, including UTF-8 and Windows-1252. When it isn’t sure, it shows a preview and lets you choose. Large exports are read in chunks, up to 8 million cells.

How it works

  1. 01

    Drop in your files

    One workbook, a handful of files or a whole folder. XLSX, XLSM, XLS, XLSB, CSV, TSV and TXT are supported.

  2. 02

    Check what you’ll get

    Choose a sheet and a column. RoWeave lists the files it will create and warns you if anything won’t carry over.

    New files land in the folder you choose. Your original stays untouched, and past runs are kept in History.

What carries over to the new files, and what doesn’t

✓ Kept

  • Fonts, fills, borders, alignment
  • Column widths, number and date formats
  • Header rows above the table, in every file
  • Row heights

β Beta, turn on in Advanced settings (off by default)

  • Sheet protection and editable cells
  • Dropdowns and data validation
  • Conditional formatting

In the “What to keep from the source workbook” section of Split and Combine.

— Not carried over

  • Pivot tables, charts, images
  • Macros: the result is a plain XLSX
Formulas

Formulas are usually replaced with the values saved in the workbook. In “Each sheet as a separate file” mode you can keep supported formulas that refer only to their own sheet. The app shows the limits before running.

Legacy and binary files in Split

From XLS (Excel 97–2003) Split carries over data, number formats and merged cells, but not fonts, fills or borders; from binary XLSB, only values.

Mixed sources in Combine

If the sources include XLS, XLSB or a text file (CSV, TSV, TXT), Combine writes the whole table as values with no formatting, including from XLSX workbooks.

Common questions

About

RoWeave is made by one developer. I keep improving the app based on what users tell me.

If something doesn’t work or something is missing, write to support@roweave.app.

How do I split an Excel file into multiple files by column?+

Open the sheet in Split, pick a column such as “City” and run it. RoWeave creates a file for each value in that column, with the same header, column widths and formats. You see the list of files before anything runs. To split a workbook by sheets, choose “Each sheet as a separate file”.

How do I merge multiple Excel files into one?+

Drop a folder of files into Combine. RoWeave takes the right sheet from each workbook, checks that the headers match and stacks the rows into one table. You can add a column with the source file name.

Why does Excel drop leading zeros when I open a CSV?+

Excel turns columns that look like numbers into numbers, so 00123 becomes 123 and long IDs turn into “1.2E+15”. Convert the CSV to XLSX in RoWeave instead: product codes, IDs and account numbers stay exactly as exported.

How much does it cost?+

RoWeave is currently free for Windows and Mac: every feature, no limits, no sign-up and no ads.

Which computers does RoWeave run on?+

Windows 10 and 11 (64-bit, x64), and Macs with Apple Silicon (M1 or later) running macOS 12.3 or later.

Will my original file be changed?+

No. RoWeave only reads your source files and never writes over them. Results are saved separately, in a folder you choose.

Will formatting and formulas be kept?+

Split keeps fonts, fills, borders, column widths and number formats. Formulas are usually replaced with the values saved in the workbook. In “Each sheet as a separate file” mode you can keep supported formulas that refer only to their own sheet; the app shows the limits before running. Combine also writes values, and keeps formatting when all sources are XLSX or XLSM workbooks. What’s kept and what isn’t

Can it handle large files?+

RoWeave converts large CSV files to Excel in chunks, without loading the whole file into memory. The limit is 8 million cells (for example, 400,000 rows × 20 columns) and 4 million rows. If there are more rows than an Excel sheet holds (1,048,576), RoWeave offers to spread them across several sheets. In normal mode, the limit for Split and Combine depends on your computer’s memory. If a workbook is too large, Split offers to “Split in parts”, with its own limits, which it shows before running.

What about password-protected files?+

XLSX, XLSM and XLSB workbooks open fine: you enter the password in the app, and it is never stored. Encrypted files in the legacy XLS format (Excel 97–2003) can’t be opened. Split can also password-protect the new files: one password for all, or a different one for each, with the list saved to a separate file.

Do I need Excel installed?+

No. RoWeave reads and writes the files itself. You only need Excel, or any other spreadsheet app, to open the result.

Privacy in the app and on this site+

The app processes Excel files only on your computer and never sends their contents over the network. It goes online only to check for updates (updates.roweave.app, or GitHub if that fails) and, when you click, to download the new version from GitHub. No file names or contents are sent, and the automatic check can be turned off. This site has no forms, ads, trackers or cookies.

“Contact support” in the app only prepares an email to support@roweave.app: you send it from your own mail, and RoWeave itself sends nothing. With “Attach diagnostics” checked, the app saves a file with technical details (RoWeave and system version, steps and timings, error codes, memory estimates) and attaches it to the email. It contains no table contents, paths or passwords.

The site and the downloads are hosted on GitHub, which sees technical connection data such as your IP address. If you email support@roweave.app, your address is used only to reply.

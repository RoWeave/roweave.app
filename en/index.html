What carries over to the new files, and what doesn’t

Kept

  • Fonts, fills, borders, alignment
  • Column widths, number and date formats
  • Header rows above the table, in every file
  • Row heights

Beta, turn on in Advanced settings (off by default)

  • Sheet protection and editable cells
  • Dropdowns and data validation
  • Conditional formatting

In the “What to keep from the source workbook” section of Split and Combine.

Not carried over

  • Pivot tables, charts, images
  • Macros: the result is a plain XLSX
  • Formulas: you get the values Excel last saved

Opens XLSX, XLSM, XLS, XLSB, CSV, TSV and TXT. From legacy XLS (Excel 97–2003), Split carries over the data, number formats and merged cells, but not fonts, fills or borders; from binary XLSB, only the values. If any Combine source is XLS, XLSB or a text file (CSV, TSV, TXT), the whole table is written as values without formatting, including the parts from XLSX workbooks.

Common questions

How do I split an Excel file into multiple files?+

Open the sheet in Split, pick a column such as “City” and run it. RoWeave creates a file for each value in that column, with the same header, column widths and formats. You see the list of files before anything runs.

How do I merge multiple Excel files into one?+

Drop a folder of files into Combine. RoWeave takes the right sheet from each workbook, checks that the headers match and stacks the rows into one table. You can add a column with the source file name.

Why does Excel drop leading zeros when I open a CSV?+

Excel turns columns that look like numbers into numbers, so 00123 becomes 123 and long IDs turn into “1.2E+15”. Convert the CSV to XLSX in RoWeave instead: product codes, IDs and account numbers stay exactly as exported.

Where can I download it?+

At the bottom of the page, under “Download”: an installer for Windows and a DMG for Mac. RoWeave tells you when a new version is out.

How much does it cost?+

RoWeave is currently free for Windows and Mac: every feature, no limits, no sign-up and no ads.

Which computers does RoWeave run on?+

Windows 10 and 11 (64-bit, x64), and Macs with Apple Silicon (M1 or later) running macOS 12.3 or later.

Will my original file be changed?+

No. RoWeave only reads your source files and never writes over them. Results are saved separately, in a folder you choose.

Will formatting and formulas be kept?+

Split keeps fonts, fills, borders, column widths and number formats. Formulas are replaced with the values Excel last saved in the workbook: the numbers stay the same, but they won’t recalculate when the data changes. Combine also writes values, and keeps formatting when all sources are XLSX or XLSM workbooks.

What’s kept and what isn’t

Can it handle large files?+

RoWeave converts large CSV files to Excel in chunks, without loading the whole file into memory. The limit is 8 million cells (for example, 400,000 rows × 20 columns) and 4 million rows; with very long text in cells it can be lower. If there are more rows than an Excel sheet holds (1,048,576), RoWeave offers to spread them across several sheets. Split and Combine keep the whole table in memory, so their limit depends on your computer: for a large file, RoWeave warns you and offers to try anyway.

What about password-protected files?+

XLSX, XLSM and XLSB workbooks open fine: you enter the password in the app, and it is never stored. Encrypted files in the legacy XLS format (Excel 97–2003) can’t be opened. Split can also password-protect the new files: one password for all, or a different one for each, with the list saved to a separate file.

Do I need Excel installed?+

No. RoWeave reads and writes the files itself. You only need Excel, or any other spreadsheet app, to open the result.

Privacy in the app and on this site+

The app processes Excel files only on your computer and never sends their contents over the network. It goes online only to check for updates (updates.roweave.app, or GitHub if that fails) and, when you click, to download the new version from GitHub. No file names or contents are sent, and the automatic check can be turned off. This site has no forms, ads, trackers or cookies.

“Contact support” in the app only prepares an email to support@roweave.app: you send it from your own mail, and RoWeave itself sends nothing. With “Attach diagnostics” checked, the app saves a file with technical details (RoWeave and system version, steps and timings, error codes, memory estimates) and attaches it to the email. It contains no table contents, paths or passwords.

The site and the downloads are hosted on GitHub, which sees technical connection data such as your IP address. If you email support@roweave.app, your address is used only to reply.

Excel을 열 기준으로 나누세요. 보고서를 하나로 합치세요.

RoWeave는 표의 행을 지점, 부서, 담당자별 파일로 나눕니다. 머리글, 열 너비, 숫자 서식은 원본 그대로입니다. 반대로 폴더에 모인 보고서를 표 하나로 합칠 수도 있습니다.

열에 있는 값마다 파일이 하나씩 생깁니다.

  • 파일을 업로드하지 않음
  • 매크로·추가 기능 불필요
  • Excel 없이도 처리

매달 이 작업을 손으로 하고 있다면

필터, 복사, 새 파일, 붙여넣기, 열 너비 맞추기. 이 과정을 부서마다 반복합니다. 아니면 만든 사람만 이해하는 매크로에 기대고 있을 겁니다.

  • 재무·회계

    부서별 보고서를 따로 보내기

    전사 보고서 하나 → 부서마다 파일 하나. 머리글과 숫자 서식은 그대로입니다.

  • 인사(HR)

    팀장에게 자기 팀 명단만 전달하기

    직원 명단 → 부서별 파일, 파일마다 다른 암호. 암호는 RoWeave가 별도 목록으로 저장합니다.

  • 물류·창고

    창고 보고서를 시트 하나로 모으기

    여러 거점에서 온 파일 30개 → 표 하나. 각 행에 원본 파일 이름을 붙일 수 있습니다.

  • 영업 관리

    담당자별 목표 대비 실적 나눠 주기

    CRM에서 내보낸 데이터(‘지역’, ‘담당자’ 열) → 지역마다 폴더 하나, 그 안에 영업 담당자별 파일.

  • ERP·은행 데이터

    앞자리 0을 잃지 않고 CSV 열기

    CSV → XLSX. 상품 코드, 사업자등록번호, 계좌번호가 내보낸 그대로 남습니다.

  • 학교·대학

    명단을 반·그룹별로 나누기

    전체 명단 하나 → 그룹마다 파일 하나. 나중에 담당 교사들의 파일을 다시 통합 문서 하나로 합칠 수 있습니다.

보통 손으로 하는 세 가지 작업

실행하기 전에 어떤 파일이 만들어지고 무엇이 옮겨지지 않는지 RoWeave가 먼저 보여 줍니다.

분할

시트 하나 → 값마다 파일 하나

전사 급여 대장→부서별 파일

자세히 보기

‘부서’ 같은 열을 선택하세요. RoWeave가 부서마다 통합 문서를 하나씩 만들고 머리글 행, 열 너비, 숫자 서식, 채우기 색과 글꼴 색을 그대로 유지합니다. 열을 여러 개 선택하면 첫 번째 열을 기준으로 하위 폴더에 나눠 담습니다. 파일마다 암호를 걸 수도 있습니다.

병합

여러 파일 → 시트 하나

지점 보고서 30개→하나로 합친 시트

자세히 보기

보고서가 든 폴더를 끌어 놓으세요. RoWeave가 각 통합 문서에서 필요한 시트를 가져와 머리글이 일치하는지 확인하고 행을 표 하나로 이어 붙입니다. 원본 파일 이름 열을 추가할 수도 있습니다. 암호가 걸린 통합 문서도 XLSX, XLSM, XLSB 형식이면 처리합니다. 암호화된 이전 형식 XLS(Excel 97–2003)는 열 수 없습니다.

CSV → Excel

CSV 내보내기 → 제대로 된 Excel 파일

ERP 내보내기→0이 남은 XLSX

자세히 보기

상품 코드와 ID의 앞자리 0이 사라지지 않고, 긴 숫자가 ‘1.2E+15’로 바뀌지 않습니다. 파일 인코딩은 자동으로 인식합니다(UTF-8, UTF-16, 유럽 언어용 Windows-1252·Windows-1250, 터키어용 Windows-1254, 베트남어용 Windows-1258, 키릴 문자용 Windows-1251·KOI8-R, 일본어 Shift_JIS, 중국어 GBK/GB18030, 한국어 CP949). 확실하지 않으면 미리보기를 보여 주고 확인을 요청합니다. 큰 내보내기 파일도 나눠서 읽으며 셀 800만 개까지 처리합니다.

사용 방법

  1. 1

    파일 끌어 놓기

    통합 문서 하나, 파일 몇 개, 또는 폴더 전체를 넣으세요. XLSX, XLSM, XLS, XLSB, CSV, TSV, TXT를 지원합니다.

  2. 2

    결과 미리 확인

    시트와 열을 선택하세요. RoWeave가 만들 파일 목록을 보여 주고, 옮겨지지 않는 항목이 있으면 알려 줍니다.

  3. 3

    결과 저장

    새 파일은 선택한 폴더에 저장됩니다. 원본은 그대로 남고, 이전 실행 내역은 ‘기록’에서 볼 수 있습니다.

보통은 이렇게 합니다

  • 수작업

    필터 → 복사 → 새 파일 → 붙여넣기 → 서식 정리. 이걸 40번 반복합니다. 한 번만 실수해도 다른 사람의 데이터가 엉뚱한 사람에게 갑니다.

  • VBA 매크로

    만든 사람이 곁에 있을 때만 제대로 돌아갑니다. Mac에서는 자주 실패하고, 매크로가 든 파일을 차단하는 회사도 많습니다.

  • 온라인 도구

    급여나 고객 데이터를 남의 서버에 올려야 합니다.

  • RoWeave

    열을 고르고 파일 목록을 확인한 뒤 ‘분할’을 누르세요. 서식은 그대로 유지되고 파일은 내 컴퓨터에 남습니다.

새 파일로 옮겨지는 것과 옮겨지지 않는 것

유지됨

  • 글꼴, 채우기, 테두리, 맞춤
  • 열 너비, 숫자·날짜 서식
  • 모든 파일의 표 위 머리글 행
  • 행 높이

베타 기능(‘고급 설정’에서 켜기, 기본값은 꺼짐)

  • 시트 보호와 편집 가능한 셀
  • 드롭다운 목록과 데이터 유효성 검사
  • 조건부 서식

분할과 병합의 ‘원본 통합 문서에서 유지할 항목’에서 선택합니다.

옮겨지지 않음

  • 피벗 테이블, 차트, 이미지
  • 매크로: 결과는 일반 XLSX입니다
  • 수식: Excel이 저장한 값으로만

XLSX, XLSM, XLS, XLSB, CSV, TSV, TXT 파일을 열 수 있습니다. 분할은 이전 형식인 XLS(Excel 97–2003)에서 데이터, 숫자 서식, 병합된 셀을 가져오지만 글꼴, 채우기, 테두리는 가져오지 않습니다. 바이너리 형식인 XLSB에서는 값만 가져옵니다. 병합할 원본에 XLS, XLSB 또는 텍스트 파일(CSV, TSV, TXT)이 있으면 XLSX 통합 문서에서 온 부분까지 표 전체를 서식 없이 값으로 기록합니다.

프로젝트 소개

RoWeave는 개발자 한 명이 만들고 있습니다. 앱이 하는 일은 세 가지입니다. 표 나누기, 파일 합치기, CSV를 Excel로 변환하기. 나머지 기능은 의견을 바탕으로 조금씩 추가하고 있습니다.

작동하지 않거나 필요한 기능이 있으면 support@roweave.app으로 알려 주세요.

자주 묻는 질문

Excel 파일을 여러 파일로 나누려면?+

‘분할’에서 표를 열고 ‘도시’ 같은 열을 고른 뒤 실행하세요. RoWeave가 그 열의 값마다 파일을 하나씩 만들고 머리글, 열 너비, 서식을 그대로 유지합니다. 실행 전에 만들어질 파일 목록을 볼 수 있습니다.

여러 Excel 파일을 하나로 합치려면?+

파일이 든 폴더를 ‘병합’에 끌어다 놓으세요. RoWeave가 각 통합 문서에서 필요한 시트를 가져와 머리글이 맞는지 확인하고 행을 표 하나로 합칩니다. 원본 파일 이름 열을 추가할 수도 있습니다.

어디서 다운로드하나요?+

페이지 아래 ‘다운로드’에서 Windows용 설치 파일과 Mac용 DMG를 받을 수 있습니다. 새 버전이 나오면 RoWeave가 알려 줍니다.

가격은 얼마인가요?+

현재 Windows와 Mac용 RoWeave는 무료입니다. 모든 기능을 제한 없이 쓸 수 있고, 가입이나 광고도 없습니다.

어떤 컴퓨터에서 사용할 수 있나요?+

Windows 10과 11(64비트, x64), 그리고 macOS 12.3 이상이 설치된 Apple Silicon(M1 이상) Mac에서 작동합니다.

원본 파일이 바뀌지는 않나요?+

바뀌지 않습니다. RoWeave는 원본 파일을 읽기만 하고 덮어쓰지 않습니다. 결과는 선택한 폴더에 따로 저장됩니다.

서식과 수식은 유지되나요?+

분할은 글꼴, 채우기, 테두리, 열 너비, 숫자 서식을 그대로 옮깁니다. 수식은 Excel이 통합 문서에 마지막으로 저장한 값으로 바뀝니다. 숫자는 같지만 데이터를 바꿔도 다시 계산되지 않습니다. 병합도 값으로 기록하며, 원본이 모두 XLSX·XLSM 통합 문서이면 서식도 유지합니다.

유지되는 것과 유지되지 않는 것

큰 파일도 처리할 수 있나요?+

큰 CSV 파일은 전체를 메모리에 올리지 않고 나눠서 Excel로 변환합니다. 한도는 셀 800만 개(예: 40만 행 × 20열)와 400만 행이며, 셀에 아주 긴 텍스트가 있으면 더 낮아질 수 있습니다. 행이 Excel 시트 한도(1,048,576행)보다 많으면 여러 시트로 나누도록 제안합니다. 분할와 병합는 표 전체를 메모리에 올리므로 한도가 컴퓨터에 따라 다릅니다. 파일이 크면 RoWeave가 경고하고 그래도 시도해 볼 수 있게 합니다.

암호가 걸린 파일은 어떻게 되나요?+

XLSX, XLSM, XLSB 형식이면 문제없이 열립니다. 암호는 앱에서 입력하며 어디에도 저장되지 않습니다. 암호화된 이전 형식 XLS(Excel 97–2003) 파일은 지원하지 않습니다. 분할 기능으로 새 파일에 암호를 걸 수도 있습니다. 모든 파일에 같은 암호를 쓰거나 파일마다 다른 암호를 정할 수 있고, 암호 목록은 별도 파일로 저장됩니다.

Excel이 설치되어 있어야 하나요?+

아니요. RoWeave가 직접 파일을 읽고 만듭니다. Excel은 결과를 열어 볼 때만 필요하며, 다른 스프레드시트 프로그램을 써도 됩니다.

앱과 이 사이트의 개인정보 보호+

앱은 Excel 파일을 내 컴퓨터에서만 처리하며 파일 내용을 네트워크로 보내지 않습니다. 앱이 인터넷에 연결하는 것은 업데이트를 확인할 때(updates.roweave.app, 응답이 없으면 GitHub)와 사용자가 누르면 새 버전을 GitHub에서 내려받을 때뿐입니다. 파일 이름이나 내용은 전송하지 않습니다. 자동 확인은 끌 수 있습니다. 이 사이트에는 입력 양식, 광고, 방문 분석 도구, 쿠키가 없습니다.

앱의 ‘지원팀에 문의’는 support@roweave.app으로 보낼 메일을 준비할 뿐입니다. 메일은 사용자가 직접 자신의 메일로 보내며, RoWeave는 아무것도 보내지 않습니다. ‘진단 정보 첨부’를 선택하면 기술 정보(RoWeave와 시스템 버전, 작업 단계와 시간, 오류 코드, 메모리 추정치)가 담긴 파일을 저장해 메일에 첨부합니다. 표 내용, 경로, 암호는 들어 있지 않습니다.

사이트와 다운로드 파일은 GitHub에서 호스팅되며, GitHub는 IP 주소 같은 기술적 연결 데이터를 볼 수 있습니다. support@roweave.app으로 메일을 보내시면 주소는 답장에만 사용합니다.

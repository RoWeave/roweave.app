다운로드

무료 베타 0.13 · Windows 10/11 및 macOS 12.3+

Excel을 열 기준으로 나누세요. 보고서를 하나로 합치세요.

RoWeave는 Excel 파일을 열 기준으로 여러 파일로 나누고, 폴더에 모인 보고서를 표 하나로 합칩니다.

무료 다운로드 사용 방법 ↓

파일을 업로드하지 않음

RoWeave는 사용자의 컴퓨터에서 파일을 처리합니다. 업데이트 자동 확인은 설정에서 끌 수 있습니다.

Excel 안에 설치하지 않음

VBA 매크로나 추가 기능 없이 쓰는 독립 앱입니다. Excel을 설치하지 않아도 되고, Windows에서는 관리자 권한 없이 설치됩니다.

실행 전에 계획 확인

실행하기 전에 어떤 파일이 만들어지고 무엇이 옮겨지지 않는지 RoWeave가 먼저 보여 줍니다.

보통 손으로 하는 세 가지 작업

분할

시트 하나 → 값마다 파일 하나

‘부서’ 같은 열을 선택하세요. RoWeave가 부서마다 통합 문서를 하나씩 만들고 머리글 행, 열 너비, 숫자 서식, 채우기 색과 글꼴 색을 그대로 유지합니다. 열을 여러 개 선택하면 첫 번째 열을 기준으로 하위 폴더에 나눠 담습니다.

‘시트마다 별도 파일’ 모드에서는 같은 시트 안에서만 참조하는 수식은 지원되는 경우 유지할 수 있습니다. 매우 큰 통합 문서에는 ‘부분씩 분할’ 모드가 있습니다. 만든 파일은 바로 ZIP으로 묶거나 암호를 걸 수 있습니다. 모든 파일에 같은 암호를 걸거나 파일마다 다른 암호를 걸 수 있으며, 암호 목록은 별도 파일에 저장됩니다.

병합

여러 파일 → 시트 하나

보고서가 든 폴더를 끌어 놓으세요. RoWeave가 각 통합 문서에서 필요한 시트를 가져와 머리글이 일치하는지 확인하고 행을 표 하나로 이어 붙입니다. 원본 파일 이름 열을 추가할 수도 있습니다. 암호가 걸린 통합 문서도 XLSX, XLSM, XLSB 형식이면 처리합니다. 암호화된 이전 형식 XLS(Excel 97–2003)는 열 수 없습니다.

CSV → Excel

CSV 내보내기 → 제대로 된 Excel 파일

CSV를 XLSX로 변환해도 상품 코드, ID, 계좌 번호의 앞자리 0이 그대로 남아 긴 숫자가 ‘1.2E+15’로 바뀌지 않습니다.

RoWeave가 UTF-8과 CP949를 포함해 인코딩을 자동으로 인식합니다. 확실하지 않으면 미리보기를 보여 주고 직접 고르게 합니다. 큰 내보내기 파일도 나눠서 읽으며 셀 800만 개까지 처리합니다.

사용 방법

  1. 1

    파일 끌어 놓기

    통합 문서 하나, 파일 몇 개, 또는 폴더 전체를 넣으세요. XLSX, XLSM, XLS, XLSB, CSV, TSV, TXT를 지원합니다.

  2. 2

    결과 미리 확인

    시트와 열을 선택하세요. RoWeave가 만들 파일 목록을 보여 주고, 옮겨지지 않는 항목이 있으면 알려 줍니다.

  3. 3

    결과 저장

    새 파일은 선택한 폴더에 저장됩니다. 원본은 그대로 남고, 이전 실행 내역은 ‘기록’에서 볼 수 있습니다.

부서 또는 출처 작업 RoWeave가 하는 일

  • 영업 관리

    명단을 반·그룹별로 나누기

    전체 명단 하나 → 그룹마다 파일 하나. 나중에 담당 교사들의 파일을 다시 통합 문서 하나로 합칠 수 있습니다.

  • 피벗 테이블, 차트, 이미지

수식

수식은 보통 통합 문서에 저장된 값으로 바뀝니다. ‘시트마다 별도 파일’ 모드에서는 자기 시트만 참조하는 지원되는 수식을 유지할 수 있습니다. 제한 사항은 실행 전에 앱이 보여 줍니다.

분할할 때 이전 형식과 바이너리 파일

이전 형식인 XLS(Excel 97–2003)에서는 데이터, 숫자 서식, 병합된 셀을 가져오지만 글꼴, 채우기, 테두리는 가져오지 않습니다. 바이너리 형식인 XLSB에서는 값만 가져옵니다.

병합할 원본의 형식이 섞여 있을 때

원본에 XLS, XLSB 또는 텍스트 파일(CSV, TSV, TXT)이 있으면 병합은 XLSX 통합 문서에서 온 부분까지 표 전체를 서식 없이 값으로 기록합니다.

자주 묻는 질문

Excel 파일을 여러 파일로 나누려면?+

‘분할’에서 표를 열고 ‘도시’ 같은 열을 고른 뒤 실행하세요. RoWeave가 그 열의 값마다 파일을 하나씩 만들고 머리글, 열 너비, 서식을 그대로 유지합니다. 실행 전에 만들어질 파일 목록을 볼 수 있습니다.

여러 Excel 파일을 하나로 합치려면?+

파일이 든 폴더를 ‘병합’에 끌어다 놓으세요. RoWeave가 각 통합 문서에서 필요한 시트를 가져와 머리글이 맞는지 확인하고 행을 표 하나로 합칩니다. 원본 파일 이름 열을 추가할 수도 있습니다.

CSV를 열면 Excel이 앞자리 0을 지우는 이유는?+

Excel은 숫자처럼 보이는 열을 숫자로 바꾸기 때문에 00123은 123이 되고, 긴 번호는 ‘1.2E+15’가 됩니다. RoWeave에서 CSV를 XLSX로 변환하면 상품 코드, ID, 계좌 번호가 내보낸 그대로 유지됩니다.

가격은 얼마인가요?+

현재 Windows와 Mac용 RoWeave는 무료입니다. 모든 기능을 제한 없이 쓸 수 있고, 가입이나 광고도 없습니다.

어떤 컴퓨터에서 사용할 수 있나요?+

Windows 10과 11(64비트, x64), 그리고 macOS 12.3 이상이 설치된 Apple Silicon(M1 이상) Mac에서 작동합니다.

원본 파일이 바뀌지는 않나요?+

바뀌지 않습니다. RoWeave는 원본 파일을 읽기만 하고 덮어쓰지 않습니다. 결과는 선택한 폴더에 따로 저장됩니다.

서식과 수식은 유지되나요?+

분할은 글꼴, 채우기, 테두리, 열 너비, 숫자 서식을 그대로 옮깁니다. 수식은 보통 통합 문서에 저장된 값으로 바뀝니다. ‘시트마다 별도 파일’ 모드에서는 자기 시트만 참조하는 지원되는 수식을 유지할 수 있으며, 제한 사항은 실행 전에 앱이 보여 줍니다. 병합도 값으로 기록하며, 원본이 모두 XLSX·XLSM 통합 문서이면 서식도 유지합니다. 유지되는 것과 유지되지 않는 것

큰 파일도 처리할 수 있나요?+

RoWeave는 큰 CSV 파일을 메모리에 한꺼번에 올리지 않고 나눠서 Excel로 변환합니다. 한도는 셀 800만 개(예: 40만 행 × 20열)와 400만 행입니다. 행이 Excel 시트 한도(1,048,576행)보다 많으면 여러 시트로 나누도록 제안합니다. 일반 모드에서 분할과 병합의 한도는 컴퓨터 메모리에 따라 다릅니다. 통합 문서가 너무 크면 분할이 ‘부분씩 분할’ 모드를 제안하며, 이 모드의 별도 제한 사항은 실행 전에 보여 줍니다.

암호가 걸린 파일은 어떻게 되나요?+

XLSX, XLSM, XLSB 형식이면 문제없이 열립니다. 암호는 앱에서 입력하며 어디에도 저장되지 않습니다. 암호화된 이전 형식 XLS(Excel 97–2003) 파일은 지원하지 않습니다. 분할 기능으로 새 파일에 암호를 걸 수도 있습니다. 모든 파일에 같은 암호를 쓰거나 파일마다 다른 암호를 정할 수 있고, 암호 목록은 별도 파일로 저장됩니다.

Excel이 설치되어 있어야 하나요?+

아니요. RoWeave가 직접 파일을 읽고 만듭니다. Excel은 결과를 열어 볼 때만 필요하며, 다른 스프레드시트 프로그램을 써도 됩니다.

프로젝트 소개

RoWeave는 개발자 한 명이 만들고 있습니다. 사용자 의견을 바탕으로 앱을 계속 다듬고 있습니다.

작동하지 않거나 필요한 기능이 있으면 support@roweave.app으로 알려 주세요.

앱과 이 사이트의 개인정보 보호+

앱은 Excel 파일을 내 컴퓨터에서만 처리하며 파일 내용을 네트워크로 보내지 않습니다. 앱이 인터넷에 연결하는 것은 업데이트를 확인할 때(updates.roweave.app, 응답이 없으면 GitHub)와 사용자가 누르면 새 버전을 GitHub에서 내려받을 때뿐입니다. 파일 이름이나 내용은 전송하지 않습니다. 자동 확인은 끌 수 있습니다. 이 사이트에는 입력 양식, 광고, 방문 분석 도구, 쿠키가 없습니다.

앱의 ‘지원팀에 문의’는 support@roweave.app으로 보낼 메일을 준비할 뿐입니다. 메일은 사용자가 직접 자신의 메일로 보내며, RoWeave는 아무것도 보내지 않습니다. ‘진단 정보 첨부’를 선택하면 기술 정보(RoWeave와 시스템 버전, 작업 단계와 시간, 오류 코드, 메모리 추정치)가 담긴 파일을 저장해 메일에 첨부합니다. 표 내용, 경로, 암호는 들어 있지 않습니다.

사이트와 다운로드 파일은 GitHub에서 호스팅되며, GitHub는 IP 주소 같은 기술적 연결 데이터를 볼 수 있습니다. support@roweave.app으로 메일을 보내시면 주소는 답장에만 사용합니다.
